Drawing Robot

Project Overview

Robot that extracts line traces from an image and reproduces them as drawings on a whiteboard. Combines image processing (MATLAB) with precision motion control (Arduino, servo motors).

Core Components

  • MATLAB/Simulink · Arduino Nano 33 IoT · motor carrier · servo motors · DC drivers · whiteboard frame · markers

Key Skills

  • MATLAB image processing · embedded C (Arduino) · sensor integration · mechanical assembly · circuit troubleshooting · motion control

Build Log · 4‑Day Sprint

Day 1 – mechanical assembly: Assembled aluminum frame, mounted DC motors and servo lift mechanism. Wired motor carrier, secured power distribution. Chassis ready for firmware.
