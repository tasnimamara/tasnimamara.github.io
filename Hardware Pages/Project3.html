Webcam Controlled Robot

Project Overview

The Webcam Controlled Robot is an ongoing mechatronics project. I will build and program a webcam controlled rover to follow paths, move objects with a forklift, and avoid obstacles.

Components Used

  • Arduino Nano 33 IoT (microcontroller)
  • Arduino Nano Motor Carrier
  • Servo Motors
  • Motor Drivers
  • Frame and Structure
  • Webcam
  • Power Supply

Skills

  • Microcontroller programming (Arduino)
  • Sensor integration
  • Mechanical design and assembly
  • Hardware troubleshooting and circuit analysis
