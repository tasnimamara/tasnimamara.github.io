Project Overview

Histogram‑fitting tool with manual/auto options. Features:

  • Manual data entry or CSV upload.
  • Fit 10 distributions (normal, gamma, Weibull, etc.) via SciPy.
  • Visualize data + fit with Matplotlib.
  • Show fit parameters + error metrics.
  • Manual mode: sliders adjust distribution params.

Stack

  • Python · Streamlit · NumPy · SciPy · Matplotlib

Skills

  • Streamlit · data visualization · statistical fitting · file I/O
